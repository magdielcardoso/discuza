## Task atual
Corrigir cor do texto das categorias no modo escuro na página inicial.

## O que foi feito
- Analisada a causa do problema da cor do texto das categorias no modo escuro.
- Identificado que uma regra CSS global em `app/assets/stylesheets/application.css` para `h1, h2, h3, h4, h5, h6` estava definindo uma cor fixa (`#111827`), sobrescrevendo a classe `dark:text-white` do Tailwind CSS nos elementos `<h3>` das categorias.
- Removida a propriedade `color: #111827;` da regra global de cabeçalhos no arquivo `app/assets/stylesheets/application.css`. Esta alteração permite que as classes de utilitário de cor do Tailwind CSS, incluindo as variantes de modo escuro, funcionem como esperado.
