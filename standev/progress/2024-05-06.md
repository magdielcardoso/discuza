- Executada a migration para criar a tabela `categories` no banco de dados.
- Atualizado o `HomeController#index` para carregar todas as categorias (`@categories = Category.all`).
- Modificada a view `app/views/home/index.html.erb` para iterar sobre `@categories` e exibir os dados do banco, substituindo os dados mockados anteriores.
- Sugerida a criação de dados iniciais (seeds) para as categorias.

### O que falta
